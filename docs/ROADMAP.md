# Scientific and formal-development roadmap

Version 0.4.0 completes a bounded concrete finite-plan milestone alongside the
accepted external observation experiment. The [claim index](../CLAIM_EVIDENCE.json)
and [trust ledger](formal/TRUST_AND_SCOPE.md) state what each result establishes.

| Milestone | Current scope | Remaining work |
|---|---|---|
| R0: external applicability | Accepted pinned SV19 observation mismatch/refusal/repair experiment, fit consequences, timing and v0.3.0 release | Additional processes, datasets and independent physics engines |
| R1: representation | Implemented finite parameter-indexed source/plan syntax, wire identity, dependencies, cache lifetime and executable counterexamples | Richer domain/units types and further supported transformations |
| R2: concrete Lean checker | Completed exact finite cache-preservation theorem; 24 library statements, selected full literals, sealed-plan execution tests | Verified decoder/Python correspondence, numerical error and broader transformations |
| R3: categorical composition | Completed interface/mask category, substitution laws, fixed-interpretation functor and transported-reference checked composition | General plan-syntax composition, physically realized broader categories and observation-specific coherence |
| R4: approximation contracts | Existing explicit numerical budgets and convergence evidence | Certified remainder/stability bounds, IEEE analysis, full-tail and perturbative error propagation |
| R5: multidimensional inference | Bounded synthetic diagnostic evidence retained | Flexible families, coupled datasets, priors, identifiability and independently checked AI proposals |
| R6: constructive process families | Research direction | Physical realization/extension or obstruction theorems and justified higher coherence structures |

The long-term aim remains AI-assisted multidimensional parton extraction and
constructive derivation/proof of factorization for specified process families.
It is a discovery program, not just a taxonomy of known calculations. It does
not assume that every process admits a chosen factorization. Higher structures
and homotopical ideas require concrete physical realization and analytic
obligations; finite response arrays alone do not establish representability.

The present result is useful because it proves a property of the actual
supported finite construction. It does not promote units/measure metadata into
a Lean proof of physics, turn empirical tolerances into categorical equality,
or infer native function purity from labels. Observation integration remains
information-losing; changing parameter boundaries also transports the model.

The immediate publication is companion software for a CPC methods project.
Manuscript scope and composition remain author decisions. Version 0.4.0 is
[archived on Zenodo](https://doi.org/10.5281/zenodo.23546800). No new scientific
campaign or manuscript revision is part of this software release or its DOI
follow-up.
