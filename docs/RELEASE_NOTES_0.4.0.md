# Version 0.4.0

A fitted-parameter cache can agree at its initialization point and still change
the family seen by a fit. This release adds a concrete finite-source/plan
checker, exact Lean preservation under fixed interpretation and admitted
variations, and source-category composition with transported cache references.

The publication includes the accepted theorem sources, strict wire/runtime
implementation, four complete positive literal roots plus a negative root,
24 theorem statement/axiom reports, readable cache/composition examples and
portable finite-coefficient replay. The selected roots cover a cache fixture,
one full finite-window output in each chart and one real-geometry bin with an
analytic callback. Runtime replay additionally compares all 100 scalar targets.

Lean 4.21.0/Std builds freshly, with a 65536-KiB thread stack for the large
certificates. Reported logical dependencies are propext and Quot.sound.
The checked exact semantics do not verify Python, decoding, callback purity,
IEEE arithmetic, quadrature or QCD. The historical abstract seed is retained.

The existing native SV19 mismatch/repair experiment and v0.3.0 release are
unchanged. No new fits, input grids, noise draws or native measurements are
introduced. Runtime-only and mandatory Lean CI are distinct. See
[reproduction](formal/REPRODUCE.md) and the release's publication receipt for
clean-checkout, anonymous-retrieval and actual CI evidence. DOI remains deferred.
