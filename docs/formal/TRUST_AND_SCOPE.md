# Trust and scope

| Layer | Established evidence | Remaining boundary |
|---|---|---|
| Scientific definition and factorization | Explicit inherited process/scheme/scales/accuracy contracts and source audit | No new factorization theorem |
| PDF inputs and discretization | Frozen identities and numerical comparisons | No certified interpolation, full-tail or perturbative remainder bound |
| Exact finite source/cache plan | 24 Lean-checked library statements, four selected positive roots and one negative root | Fixed pure interpretation and admitted variation slice required |
| Category | Concrete interface/arrow/substitution and interpretation laws; transported-reference composition | No general plan-syntax category or category of all physical TMDs |
| Wire decoder and literal encoder | Strict schema, mutation tests, artifact hashes and audited generated terms | No formally verified JSON/Python correspondence |
| Python plan execution | Same sealed plan, fixed-coordinate/context guards and runtime comparisons | Callback purity and numerical implementation remain obligations |
| Native backend | Preserved adapter/source audit and historical numerical campaign | Mutable hidden state is not proved pure by a type tag |
| IEEE arithmetic and exp | Executed values and explicit tolerances | No rounding or transcendental-error proof |
| Fitting and coverage | Saved controlled synthetic experiments | No identifiability, calibrated confidence or new experimental extraction |

The actual logical axioms reported by the formal library are `propext` and
`Quot.sound`. The [claim index](../../CLAIM_EVIDENCE.json) distinguishes
`kernel_checked`, `runtime_tested`, `numerically_compared`,
`historical_native_execution`, `not_claimed` and dependency-blocked work.

The new observation certificate binds an analytic polynomial callback on real
geometry. The separate historical external study uses arTeMiDe/SV19. Neither
the analytic certificate nor native-versus-typed agreement proves native QCD,
the complete fit, or all hidden global state. Independent observation
quadrature shares the same physics engine; it is not an independent QCD engine.
The point/bin fault is deliberately injected at the analysis interface, not a
discovery of an upstream physics-code bug.

A parameter-independent cache can be exact under the finite source model
without establishing that model's physical adequacy. Evidence identifiers and
successful numerical tests are not a semantic equality oracle. Unsupported
maps, including an unregulated TMD integral advertised as an exact collinear
PDF identity, receive no new authorization from this work.
